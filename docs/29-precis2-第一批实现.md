## 1. 这一层要解决什么

第二篇要回答的不是"试验好不好"（不是偏倚风险、不是质量分、不是疗效），而是：
**这项针刺试验有多接近真实临床（pragmatic），有多接近理想实验（explanatory）**，
按 PRECIS-2 的九个领域各给 1–5 分（可带 `3-B / 3-U / N/A / AS` 标签），
每分都要有原文证据与评分依据。

05 是评分作业说明书；06 的 **223 行、九个领域全部有人工评分**，是现成的基准答案。
所以第一步不是"再找人评一遍"，而是：**让机器先评，算它和人差在哪**——差得多的领域，
才是需要专家复核/仲裁的地方。

## 3. 金标准加载：223 行怎么变成 222 篇

06 的 A 列是"行号"（`2015-04-01`），B 列是文章号（`2015-04`），两者与仓库金标准 ID 都有漂移：

- 11 处 `A ≠ B`，其中 6 处是跨年笔误（如 `2022-05` 那行 B 写成 `2024-05`）；
- 2015–2019 的 `-01` 是比较组后缀，仓库金标准用 `2015-04`；
- 2025-01 与 2025-02 **题名完全相同**（同题两篇）。

因此匹配顺序是 **标题（≥0.9）→ 精确 ID → 去后缀 → 同年同号**；
同题并列时**必须**用 ID 打破，否则会取错年份。结果：

```
223 行 → 222 篇（一行重复 2024-19，评分一致，合并）
217 篇九领域齐全；5 篇缺 1 个领域（4 处依从、1 处纳排）
无未匹配、无冲突重复
```

`/`（06 里的 N/A）**不猜成 3**；空值是缺失，不进一致率分母。

## 4. SKILL 的设计（为什么不是"让模型打分"）

沿用第一篇的硬约定：**模型只回传分数 + 逐字引文，坐标由本地定位**。

- 九领域固定顺序；每个领域返回 `score / quotes / evidence / rationale / confidence`；
- `quotes` 在 MiniDoc 里定位成功才算"接地"；定位不到 → `grounded=false` + issue + 进 `unresolved`；
- **3-U / N/A 允许没有引文**（信息不足本来就没有可引原句），但 evidence 里必须写清"哪一节/哪一页缺什么"；
- 校验器拦：3-B 与 3-U 混用、N/A 越界（只允许灵活性-依从）、AS 格式、缺依据/缺证据摘要；
- 汇总只排除 N/A 与 AS，3-B/3-U 记 3（3-U 单独计数）——**不是**官方总分。

提示词里写死了 05 的判分锚点，并针对实测偏差做了四处校准（v0.2.1）：

| 校准 | 原因（实测） |
|---|---|
| 常规转诊/筛查路径算"已描述"，不因没写 consecutive 给 3-U | 2016 年有 10/21 被误判 3-U，人工给 3–5 |
| 单一普通临床点 3、**多个普通临床点 4** | 机器默认 3-B，人工多为 4；Setting 的 kappa 一度只有 0.03 |
| 常规针灸疗程不算依从负担；**日记若本身是结局测量，负担记 Follow-up** | 依从被系统性压低（机器均值 2.6 vs 人 3.2） |
| 5 = 全 ITT + 可辩护缺失处理；敏感性分析是佐证不是必要条件；**只看主要结局的主要分析** | 人工对 ITT 给 5，机器因次要结局排除或"没写敏感性分析"压到 4 |

## 5. 全量数字（222 篇 / 1911 格，SKILL v0.3.0）

| 指标 | 值 |
|---|---|
| 有机器产物的研究 | 224（含 2 篇 06 未收录） |
| 能与金标准匹配的研究 | **222 / 222** |
| 可比较领域格数 | 1911 |
| 完全一致（整数相等） | **48.0%** |
| ±1 以内 | **91.0%** |
| 二次加权 kappa | **0.74** |
| 严格口径 kappa（3-U 不算可比较） | **0.77** |
| MAE | 0.63 |
| 平均有符号差（机器 − 人） | +0.04 |
| 3-U 次数 | 111（5.8%） |
| 未接地分数 | 11 |

逐领域（完全一致 / kappa / 平均差 / 3-U）：

| 领域 | 一致 | kappa | 平均差 | 3-U |
|---|---|---|---|---|
| 纳排 | 40.7% | 0.38 | −0.10 | 2 |
| 招募 | 15.8% | 0.51 | +0.03 | 12 |
| 场所 | 67.1% | 0.61 | −0.04 | 2 |
| 组织与资源 | 44.6% | 0.20 | +0.38 | 2 |
| 灵活性-实施 | 69.2% | 0.76 | −0.15 | 5 |
| 灵活性-依从 | 27.3% | 0.25 | +0.33 | 0 |
| 随访 | 41.9% | 0.57 | +0.16 | 0 |
| 主要结局 | 77.0% | 0.68 | +0.14 | 18 |
| 主要分析 | 39.6% | 0.55 | −0.29 | 70 |

**读法**：完全一致不到一半不等于机器"错"——PRECIS-2 相邻档（3-B 与 4）本来很细，
人工之间也未必一致；±1 九成、kappa 0.74 说明机器已经把剖面的大方向抓住了。
真正要拿去和医生讨论的是**逐领域的平均差与 kappa**：

- 实施灵活性（0.76）、主要结局（0.68）、场所（0.61）已经可用；
- 依从（0.25）、组织与资源（0.20）、纳排（0.38）是下一轮要补的；
- **主要分析仍有 70 次 3-U**（31.5%）——多数是论文没写分析人群/缺失处理，
  这正好是专家复核最该先看的队列，而不是机器"乱猜"。

对照：v0.2.1 在 2015–2016 的 21 篇上是 48.9% / 90.7% / kappa 0.74；
全量扩到 222 篇后基本持平，说明这版提示词不是只拟合了前两年。
（v0.3.0 的主要改动是把"招募 3-U"从 92 次压到 12 次、把"主要结局 3-U"从 50 压到 18。）

## 6. 已知边界（下一轮先解决这些）

1. **补充材料没进 MiniDoc**。05 §2 要求协议/附录与正文一起看；当前 `Source Audit` 会把
   `-sup.pdf` 标成"not ingested（待补）"。这会直接影响招募、组织、分析三个领域。
2. **21 个研究特征字段只填了能拿到的**（题目/DOI/国家/疾病/干预/对照），
   `随机/分析例数` 等要等第一篇文章的抽取产物重跑后再补。
3. **三人盲评 + 第三方仲裁还没有数据层与界面**。目前只有 `build/precis2/<year>/<id>.json`
   一份机器产物；下一步按第一篇的多核对人模式实现：
   `build/precis2-review/<year>/<id>.<reviewer>.json`，两票一致即定、不一致进仲裁队列。
4. **一致率不是准确率**。06 的人工评分是基准，但基准自身有主观性；
   报告里不能写"机器准确率 48.9%"。
5. **3-U 的无引文是设计选择**：absence-based 分数在数据上无法"接地"，
   所以看板必须把 3-U 单独标出来，而不是混进"有证据"里。
6. **提示词校准用了 2015–2016 的 21 篇**，全量 222 篇复核后总体一致率基本持平；
   但逐领域仍有明显偏科（依从、组织），下一轮要拿专家复核结果定位是提示词还是材料问题。
