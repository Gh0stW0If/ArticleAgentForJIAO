# 测量单位与缺失数据优化

本次修改同时接入四步客户端和旧版 comparison/outcome 提取。既有人工参考表、历史抽取 JSON 和26篇验收数据保持原状。正常重新运行“基础字段”会使用新的缺失数据提示词；重新汇总选中结局会提取测量单位。仅导入历史基础字段不会生成新的缺失数据口径。

## 测量单位

保存原文单位和规范值，统一 minutes/min、毫升/mL 等同义写法。自 0.2.2 起，原文以量表得分报告时，原文单位和出处保留 points、score 或分等写法，规范单位记为 NA。明确报告 mm、cm 等单位时保留相应单位。不自动把 cm 换成 mm，也不换算估计值、SD或CI。mM 与 mm 的大小写含义不同，单独处理。

优先读取选中结局自己的行标题、表头、脚注、方法定义。旧版 outcome 在名称或测量范围中有明确单位及原文证据时可补全单位。四步汇总在每条记录上保存单位及来源，并支持人工修改。

NR 为未报告；NA 为单位不适用，例如量表分数；NE 为无法提取；明确无量纲另行记录。找不到单位不会直接填 NA，量表名称或0—100范围本身不证明单位为 mm，样本量 n 不作为均值单位。

客户端展示“单位”“原文写法”和“单位来源”。修改单位不会自动修改数值。Excel及CSV增加规范单位、原文单位、状态及来源列，仍保留原四张工作表。

## 缺失数据

每个比较组按组别、结局、时点、人群记录以下人数，并分别保留原文证据：

- randomized：随机人数。
- observed：该结局该时点实际有观测值的人数。
- analyzed：纳入分析人数。
- imputed：插补人数。
- dropout：退出或失访人数。
- missing：该结局缺失人数。

保留原文直接报告的比例及程序计算比例，两者不一致时提示口径冲突。百分号明确时才转换，例如3.6%规范为0.036；裸值3.6不擅自解释为3.6%。

程序只用“缺失人数/随机人数”或“(随机人数−实际观测人数)/随机人数”推导。分析、插补和脱落人数不能自动代替缺失人数。只有有主要结局声明、完整口径及同一时点人群证据时，才回填主要结局缺失比例。两臂合计先相加分子分母，不平均两个百分比。多时点、多分析人群、重复组别、人数冲突会保留待核对提示。

客户端基础字段中新增“缺失数据口径”展开区，分别展示各人数、比例及来源。计算值会标为程序推导。原文是否直接报告缺失数据的编码不会因程序能计算而自动变成“已报告”。流程图识别复用现有本地OCR，成功结果按图像内容和识别脚本缓存。

## 小样本验证

隔离输出位于 build/units-missing-validation/2026-11-21，未修改正式提取或人工金标准。

2018-02：原文支持第8周主要结局相关数据缺失，电针组6人、假针组5人；每组随机180人。程序推导11/360≈3.06%，保留两组原文来源。该比例与整项研究退出人数的口径不同。

2016-01：主要结局分析人数536与539等于随机人数，但原文提到了多重插补。缺少同口径实际观测或缺失人数时，程序保留NR，不据分析人数推断0%。安全性分析人数也未代替主要结局人数。

这些是功能及原文证据验证，不是新一轮26篇金标准准确率评估。

测试覆盖单位别名和大小写、单位缺失状态、明确单位补全、ITT与观测人数、脱落和缺失区别、分组合计、多时点/人群、比例冲突与无来源人数，以及界面的单位修改、人数展示和Excel导出。
