## 新格式标准

每条结果保存原值、规范值和来源。规范值供比较和合并使用，原值与页码、表编号、行列标题供人工复核。现有三张表可以继续作为导出视图，通过映射生成正确的列值。

| 字段 | 规范值 | 比对规则 |
| --- | --- | --- |
| 性别分布 | 存试验臂、统计人群、男性人数、女性人数。只给男女比例时存比例，只给总体时存总体。例如试验组可显示为“男 121，女 415”。 | 先按同一试验臂和统计人群对齐，再比计数。分号、斜杠、文字标签和输入顺序经解析后可以统一。 |
| 测量单位 | 保存规范代码和原文单位，如 VMS/day、分、mL、分钟、%。单位为空时注明未报告、无单位或不适用。 | 同一含义可统一文字别名。单位换算时同时换算点估计和适用的离散度。 |
| 人数、事件数及比例 | 分设随机人数、实际观测人数、分析人数、插补人数和脱落人数。二分类单独存事件数与分母。比例按 0 到 1 保存，并附分子、分母和人群口径。 | 只对同一人群、同一统计定义进行百分比换算和原文精度比对。事件数应在同口径分母范围内。 |
| 结局与时点 | 存结局、量表、分域、报告时点及对齐后的标准时点。保留原文第几周、随访自何时起算和实际比较组。 | 同一名称须核对量表与分域。第 8 周的绝对值和第 8 周较基线变化量作为两条独立记录。 |
| 点估计和离散度 | 点估计注明均值、中位数、组间差、比值等。SD 和 SE 各存一个值。CI 存置信水平与上下限。IQR 存 Q1、Q3。 | SD 可以为 0。区间两端按顺序保存，并核对估计值、两端和统计类型的来源。单值统计量走单值检查。点估计来源与区间来源跨表时，需能证明来自同一估计对象。 |
| P 值 | 存关系符、数值、比较、时点与检验说明，如小于 0.05。 | 保留阈值的关系符。用原文确认检验对应的是组间比较、组内比较，或另一项次要分析。 |
| 缺失或冲突 | 区分未报告、不适用、原文冲突、附表未获得和已报告但未提取。 | 各类状态单独统计。原文同一口径出现冲突时保留两处证据，待人工裁定。 |

规范化只处理写法、单位和可证明的精度差异。首次比较采用有原文证据的规范值，任何疑似换了试验臂、结局或时点的记录进入归属检查。

## 实施顺序

1. **先把规范化接到评估和导出。** 用已有产物离线复算，保留原文、规范值和修正理由。优先跑性别、单位、比例和 P 值样例，复核原本的低命中有多少由格式解释。旧版与新版用同一规则评分。
2. **修正统计结果的写入校验。** 把结果的唯一定位定义为研究、比较组／试验臂、结局／分域、时点、分析人群及统计口径。比较组名称由试验臂标识展示，取数与审计按标识回填。SD、SE、CI、IQR 和人数校验在初提与补填共用。复核阶段只接收带目标标识的候选，最后写盘前再验一次。涉及 PDF 解析数字或脚注冲突时，重新读取对应原页。
3. **补齐结局清单和可追溯性。** 结局规划后增加覆盖检查，联合方法段明确声明的主要结局、结果表／图标题和附表引用。候选逐条记录已纳入、重复、超出项目范围、附表待补或还未取到。先验证 CSBM、导尿频率和 FLIE 三种情况。
4. **做小批对照再扩大范围。** 固定同一批 PDF、同一模型和同一抽查基准。先用上述案例验证规范化和写入规则，再跑受影响阶段，最后在 26 篇上复核结果。保存每次处理的规则版本和关键证据页，便于定位分数变化。
