03 · 提取表的 3 个 Sheet 说明 —— 规则最多、最需要照做

Sheet1（文章级 + 比较组级，约 91 列）的规则分成六类：

  • 结构操作：编号由「批次 + 文献编号」两列合并成唯一编号；另有 5 列明确不要。
  • 引用别的列来判定：疾病分类和「是否与手术/急性发作相关」都参考「疾病名称 / 疾病系统」两列来定；影响因子按最新版更新，不再锁死 2019 年。
  • 照抄原文：约 9 列要求逐字复制原文（干预方法、对照组名称、随机方法、分配隐藏、选穴分类、治疗频次描述等）。
  • 常规提取：约 50 列。
  • 「单位匹配 → 换算 → 报错确认」三段式（12 列）：治疗频次（数值 + 单位）、疗程、治疗总次数、留针时间三段、针数、最长随访（描述 + 数值 + 单位）。能对上原文单位就照记，对不上才换算，再不行就明确写「报错 / 待确认」，不许硬填。
  • 报告判定 1 列：刺激强度只在原文写了「强 / 弱」时照写，没写就写「没报告」——不做主观定义。

此外有一列溯源：记录这一条是「谁」参与提取的（人还是机器），便于以后追溯责任。

Sheet2（结局分类）：先判定主结局——原文标明「主要结局」的优先，否则取第一个出现的患者重要结局； 然后把结局归入六类（疼痛 / 非疼痛症状 / 功能 / 生活质量 / 重要事件 / 死亡率）。 归类要两个人独立核对，有分歧由第三人定。另有一列自由备注，人和机器的任何疑问都写在那里。

Sheet3（结局 × 时点）：

  • 疾病分类列必须与 Sheet1 一致（联动）。
  • P 值：原文有数值就写数值，没有就看表格和文字描述。
  • 量表的测量范围 / 方向 / 单位：去查公开量表；查不到就写「未报告」，不许猜。
  • 测量类型与基线调整走三段式：组间差值 > 估计值 > 基线调整（有组间差值就用组间差值）。
  • 要标注主要结局到底报告了哪些时点（治疗 + 随访都有 / 只有治疗 / 只有随访 / 都没报告）。
  • 数据分三块：基线期、疗程结束时、随访期；时点优先取「疗程结束」，并和 Sheet1 的最长随访对齐。

04 · Meta 分析规则 —— 什么能合、什么绝对不能合

四个前提必须同时满足，才能把研究放进同一个池：

  1. 干预 ↔ 对照组一致（比较类型）；
  2. 结局评价方面 + 量表一致；
  3. 结局类型一致（连续型 / 二分类 / 等级 / 生存）；
  4. 评价时点一致（「疗程结束」与「随访」是两个不同的池）。

四条都满足 → 计算效应量（连续型 MD/SMD，二分类 OR/RR/RD，生存 HR）→ 异质性（Q + I²）→ 森林图 / 漏斗图。

三条禁忌
  • 干预 / 对照不一致是合并的最大禁忌，必须严格分组。
  • 量表不同不能强行合并，优先做标准化处理或分池。
  • 同一个研究里「治疗结束」和「随访」的数据不能进同一个池。

05 · PRECIS-2 agent 规格 —— 第二篇的作业说明书

PRECIS-2 要判断的是：这项试验有多接近真实临床（实用性），有多接近理想实验（解释性）。 它不是偏倚风险评价，不是质量打分，也不是疗效判断。

  • 九个领域，每个领域都要给三行：评分 / 原文证据 / 评分依据。
  • 评分标签：1 极解释性 · 2 偏解释性 · 3-B 真正平衡 · 3-U 信息不足或相互矛盾 · 4 偏实用性 · 5 极实用性 · N/A 不适用 · AS: 需要按组分别评分。
  • 要严格区分：3-B 只能用于「设计本身就是中间态」，3-U 只能用于「证据不足或自相矛盾」，两者绝不能混用。
  • 证据要写到页码 / 表图号；摘要不能作为评分依据；方法与正文冲突时必须把冲突写出来。
  • 交付为横向矩阵：每一行是一个字段，每一列是一项研究；同时给 Excel 和可直接打开的网页。

06 · PRECIS-2 基本信息表 —— 第二篇现成的评测基准

我们对这张表做了实测解析，结论如下（这些数字都可复现）：

  • 单张表，共 225 行 = 3 行表头 + 223 篇研究，编号从 2015-01 一直到 2025-32，覆盖全部年份。
  • 表的后半部分依次是：偏倚风险 D1–D5 → PRECIS-2 九个领域 + 总分 → 敏感性分析 → 主结局的小数据块。
  • 九个领域已经全部有人工评分，取值就是 1–5 的数字；个别格子写「/」，代表该项不适用或需要按组分别评分。223 行里只有 1 处领域分缺失。
这意味着什么 第二篇不用从零开始定标准——这 223 篇的人工评分可以直接当作「标准答案」，用来衡量机器评得准不准，也是三位专家复核时的起点。

2.3 两个必须先说清的口径问题

口径提醒一：05 和 06 的记分方式不一致 05 要求使用 3-B / 3-U / N/A / AS 这套标签，而 06 表里的 223 篇实际只写了 1–5 的数字和「/」。 建议做成「数值 + 标签」双轨：数值用于和 06 直接比对，标签用于表达「平衡 / 信息不足 / 不适用 / 需按组评分」。 这样既不会丢掉新规格的表达力，也不会让已有的人工评分失去可比性。
口径提醒二：03 的列字母是早期版本的布局 03 里用的是「A 列、D 列、J/K 列」这样的列字母。但原始表格在 2019 年 → 2020 年之间整体左移过一列， 而 06 那张表又在最前面多插了一列——所以同一份规则，在不同年份的表格里列号是不一样的。 因此这些规则必须按字段名落地，不能按列号写死，否则后十年会集体错位。

做什么

任务二：建 PRECIS-2 提取模型，并在程序里补上「三人盲评 + 第三方仲裁」对应 07 第 2 条

做什么

做完你能看到：223 篇的九领域机器评分，以及与人工评分逐领域的一致率； 三位专家在界面上独立打分、分歧自动汇总、仲裁结果留痕；可按 05 的格式导出 Excel 与可直接打开的网页。

4现状对照：已有什么、缺什么

已经有的还缺的（都是新方向直接要求的）
  • 2015–2025 十一个年份的文章都跑通了自动抽取
  • 三张表都有逐字段的准确率评测（当前整体约 48.9%）
  • 界面上已有人工修改功能：改值 / 补录 / 确认，且不会覆盖机器的原始结果，随时能对比
  • 可打包成桌面程序，离线使用
  • 完全没有 Excel / CSV 导出——而医生做人机核对必须拿到文件，这是第一件要补的
  • PRECIS-2 相关代码一处都没有，第二篇要从零建（好在有 223 篇人工评分可做基准）
  • 人工修改目前只支持一个人，没有「三人盲评 + 第三方仲裁」
  • 二分类 / 生存结局的 OR、RR、RD、HR 抽不出来，第三篇因此无法开算
  • 评测结果与抽取结果之间存在版本不一致，报数前需要先对齐

一句话：抽取的地基已经打好，但「导出给人核对」和「多人评审」这两条通道还没有修，而它们恰好是医生这次最关心的两件事。

5需要确认的四个问题

107 里说的「小程序」，指的是哪一个？

建议：沿用现有的桌面程序 / 网页界面来补「人机核对」功能——它已经有人工修改的底层机制，改造成本能压到最低。 如果医生指的是微信小程序，那是另一套前端，需要单独立项（数据层和接口仍可复用）。

2PRECIS-2 的记分方式采用哪一种？

建议：「数值 + 标签」双轨。数值（1–5）用于和 06 的 223 篇人工评分直接比对，标签（3-B / 3-U / N/A / AS）用于表达平衡、信息不足、不适用、需按组评分。 06 里已有的「/」按此规则映射，不修改原始数据。

3第三篇的输出与结果形式，先给哪一种？

07 明确要求先讨论。可选：(A) 先出一份完整的森林图 + 结果表样例，用真实数据说话； (B) 先出一份「哪些研究能配成池、为什么」的清单，确认规则无误后再算。 建议先做 B 再做 A：配池规则一旦有偏差，后面所有数字都要重算。

4三篇并行的排期怎么定？

建议：先集中把任务一的导出与人机核对通道打通（这是医生现在就要用的），同时并行启动任务二的 PRECIS-2 模型； 任务三在任务一的中段并行补抽取缺口。
